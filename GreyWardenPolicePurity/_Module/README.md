# GreyWarden / 灰袍守卫

灰袍守卫为《骑马与砍杀 II：霸主》加入一个会在大地图上真实办案的独立执法家族。六名灰袍领主会侦查犯罪、追捕领主、组织协力军团、救济村庄并培养后继者。玩家既可能因犯罪受到追捕，也可以赢得信任、加入灰袍并接受委托。

本次 v1.4-r13 适用于 Bannerlord 1.4.8。使用 1.5.2 的玩家请选择此前发布的 v1.5-r1；本次新增内容尚未发布到 1.5 分支。
English: README_EN.md

## 主要内容

- 灰袍领主会各自带队处理练兵、商路保护、乡土保护、地方请求、村庄重建和玩家事务，成年后继者会继承仍然存在的职责。
- 灰袍会记录袭击商队、攻击村民和劫掠村庄等犯罪，按职责和距离追捕目标；强敌会引来协力军团，过快的目标可能遭到骑兵截击。
- 案件总卷会显示未结案件、承办队伍和司法公库。被捕领主会留下案底并受到逐渐恢复的震慑，累犯会受到更强的长期压制。
- 玩家可通过保护平民和协助办案提高声望并加入灰袍，随后领取悬赏、订购士兵、获得战场支援、村民酬谢与封地申诉资格。
- 灰袍会通过真实会合换防和交付士兵，处理地方请求、重建被毁村庄，并管理案件收入、行动支出和海战船只。
- 模组包含灰袍兵种树、黑金装备、自带战斗效果的灰袍武器、灰袍战马、专属盾牌、双持剑、踢击、盾击、被动大盾防护，以及与灰袍领主切磋的内容。灰袍在战场上死战不退，并有专属的战场配乐。

- 灰袍声望达到 20 后会收到雇佣邀请。接受雇佣后才能使用队内灰袍士兵的派遣对话；接新委托还需保持足够声望并穿着灰袍指挥官套装。
- 玩家受托办案可交涉、收缴钱货、押送犯人，也能派遣士兵求援或代为交差。私留办案所得与过度执法可能引来后续调查。

## 安装与更新

1. 删除旧的 Modules/GreyWarden 文件夹。
2. 将压缩包中的完整 GreyWarden 文件夹解压到游戏 Modules 目录。
3. 在启动器中启用 GreyWarden。

既有战役存档可以继续使用。更新前正在进行的旧悬赏不做衔接，请先结案。更新时请替换完整模组，不要只覆盖部分文件。

## 更新日志

### 2026-09-25 v1.4-r13（Bannerlord 1.4.8）

相较 v1.4-r12：

#### 新增与调整

- 新增灰袍战场配乐：任意一方的普通士兵有一半以上是灰袍时，战斗改用辛迪加风格的分段配乐，乐曲强弱随战况起伏。
- 灰袍在战场上死战不退：士气照常起落，但不会溃逃。
- 战场支援改为三次机会：本方兵力跌到开战时的两成、一成和只剩最后一人时各判定一次，成功一次即止。支援规模按敌方剩余兵力决定，灰袍声望越高，支援越容易到、来得越多。战场上的灰袍士兵和灰袍领主也能等到支援，不论他们站在哪一边；自定义战斗中以灰袍身份出战同样有效。
- 灰袍兵种整体提高一阶；每名士兵出场时穿戴同一套完整装备，不再东拼西凑。
- 灰袍武器自带战斗效果，谁拿谁有：灰袍单手剑、钉头锤、双手剑和骑枪有机会击倒、打下马或破开武器招架；双刀击倒更频繁；灰袍穿刺箭能击倒步行的敌人，打盾伤害加倍；灰袍大盾更耐打。
- 灰袍重步兵改用新的灰袍卡拉德钉头锤，灰袍弓箭手改用新的灰袍穿刺箭。
- 灰袍骑士改为骑枪配双手剑，不再带单手剑和盾；骑枪更长，下马后也能架枪。
- 灰袍骑士改骑新的灰袍战马：冲撞更容易撞飞、撞倒步兵，不容易受惊人立，挨小伤不受影响；骑手受到的伤害由人和马各担一半。任何人骑上灰袍战马都有这些效果。
- 玩家和灰袍弓箭手的双刀改用同一把副刀。
- 踢击、盾击和射箭在本场战斗中积累的技能加成设有上限。
- 灰袍派出的各类临时队伍和你派出的使者都不再需要口粮，长期在外也不会挨饿。
- 派使者不再需要准备口粮和盘缠。使者身上押有俘虏时，会顺路进城卖掉。
- 灰袍的临时队伍会向灰袍领主借船，你的使者会向你借船，都能渡海；你在海上又没有多余的船时，不能派出使者。
- 在野外击溃委托目标即可回去复命，领取全额办案费；把人押来交给灰袍，还会另得一笔赎金。
- 练兵随行队伍在练兵官打仗、随军团出征时也会一直跟着他。
- 从灰袍领主队里调出去的截击队，原领主战败或被俘时，会把人交给最近的灰袍领主，不再流失。

#### 修复

- 练兵订单可能永远凑不齐、无法交付：随行队伍里混进其他兵种或外来士兵后占满名额。现在这些人会被退回，名额由订单兵种补上。
- 随行练兵队会把一部分士兵练成订单以外的兵种。
- 账簿显示的练成人数与实际能交付的人数不一致。
- 随行练兵队和使者长时间在外会饿伤减员。
- 击溃委托目标后，有时被误判为目标已被别人了结，只能领辛苦费。
- 帮灰袍打仗惹上的战争，有时找灰袍领主时没有调停选项。
- 骑兵冲进灰袍弓箭手群时，游戏可能崩溃。
- 灰袍弓箭手拔出双刀后迟迟换不回弓。
- 灰袍大盾被动挡下攻击时仍会掉血并出现硬直。

### 2026-09-17 v1.4-r12（Bannerlord 1.4.8）

相较 v1.4-r11：

#### 新增与调整

- 灰袍追捕时会一路咬住目标，而不是赶往对方早先出现的地方。目标比自己快也不会再被轻易甩掉。
- 目标躲进城镇或城堡时，灰袍会在城外围住，不再跟进城里。
- 灰袍会按对手当前的实力决定出动多少人：对手身边的人散了，多余的灰袍就回去干自己的活。城镇和城堡的守军不再被当成对手的帮手。
- 灰袍之间调兵不再让队伍陷入长时间的混乱减速。
- 灰袍现在会自己买卖船只，不会再长期无船可用、被水路挡住去路。
- 闲下来时，灰袍会分散到各地巡逻，不再扎堆在同一片地方，出事时能更快赶到。
- 兵力吃紧的灰袍不会再接下明显办不成的案子；接不了的案子留在卷宗里等人手宽裕。
- 一时凑不出人手的案子不会再凭空消失，它会退回卷宗等别人接手。
- 罪犯换了效忠对象也不会让追捕作废；被别人打垮但人还活着的罪犯，重新拉起队伍后照样会被灰袍找上门。
- 把罪犯的队伍打垮，与把人拿下一样会让对方长记性。
- 加入灰袍时会一并得到全套指挥装备、一副双刀和五名灰袍新兵。
- 地图右下角的信息条中可以查看你的灰袍声望（展开信息条后显示）。
- 因为帮灰袍出手而结下的仇，现在找任何一位灰袍领主都能请他们出面了结，不必先成为灰袍的一员。

#### 修复

- 与灰袍家族成员成婚后，每次进入游戏所有人物的技能与专长都被重置。
- 双刀的说明栏显示报错文本。
- 鼠标悬停在灰袍队伍上时提示框报错、什么也不显示。
- 灰袍入会装备会多发一面盾。
