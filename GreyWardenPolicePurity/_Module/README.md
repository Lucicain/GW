# GreyWarden / 灰袍守卫

灰袍守卫为《骑马与砍杀 II：霸主》加入一个会在大地图上真实办案的独立执法家族。六名灰袍领主会侦查犯罪、追捕领主、组织协力军团、救济村庄并培养后继者；玩家既可以因犯罪遭到审判，也可以凭行动赢得信任，加入灰袍并接受委托。

适配 **Bannerlord 1.4.x（1.4.5、1.4.6、1.4.7）**，三个游戏版本使用同一个安装包。
English: [README_EN.md](README_EN.md)

## 主要内容

- **活跃的灰袍家族**：六名初始女性领主各自带队行动，分别负责练兵、商路、乡土、地方请求、村庄重建和玩家事务。成年后继者会继承仍然存在的职责；最后一名任职者死亡后，该职责也可能永久断绝。
- **全大陆执法**：灰袍记录袭击商队、攻击村民和劫掠村庄等犯罪，按距离和职责分派案件。追捕会形成有明确理由的临时执法战争；目标过强时会召集协力军团，目标过快时会派骑兵先行截击。
- **案件、案底与震慑**：案件总卷显示未结案件、承办队伍、协力任务和司法公库。被灰袍抓获的领主会留下长期案底，并按犯罪类型受到逐渐恢复的震慑；累犯的最低压制会不断提高。
- **玩家声望与执法路线**：保护村民和商队、协助灰袍办案会提高声望；袭击平民、烧村、强征或拒捕会降低声望。轻罪会招来纠察队和罚金，重罪会由正式灰袍领主追捕，并可能进入押送或赎罪任务。
- **加入灰袍与悬赏**：达到要求后，使者会主动寻找玩家。加入后可领取指挥官装备、接受现有罪犯的悬赏、获得灰袍护送队和侦查更新，并在结案后领取报酬。玩家也可以退出，并在更高声望下申请重新加入。
- **声望支援**：成员可下达调兵订单，由练兵官从真实灰袍部队中收集、训练并亲自交付士兵；高声望会扩大订单、解锁精锐兵种并降低价格。符合条件时还可获得战场增援、领取村民酬谢，并在参与攻城却未获封地后提出封地申诉。
- **练兵与真实换防**：练兵官会培养灰袍部队，并与其他灰袍领主在定居点会合，以精锐士兵换取仍可训练的低阶士兵。订单库存不足时也会通过同样的实体会合逐队调拨，不会凭空生成兵员。
- **村庄与地方事务**：灰袍会处理原版城镇、村庄请求，重建被烧毁的村庄，并在灾后救济中收养女孩作为家族后继者。人物成长、来源和收养历史会留在百科中。
- **司法公库与海战兼容**：罚金、调兵收入、案件拨款和村庄保护费进入公库，重建等行动会消耗资金。启用海战内容时，灰袍会按部队需要管理船只，并出售多余缴获船只。
- **可查信息**：任务日志中的目击地点、人物百科里的案底地点可以直接打开定居点百科；灰袍战争页面会说明追捕、拒捕或悬赏等真实宣战原因。
- **专属战斗内容**：包含灰袍兵种树、黑金装备与指挥官盾，以及踢击、盾击和被动大盾防护。和平状态下还可与灰袍领主进行城内或野外切磋。

## 安装与更新

1. 删除旧的 `Modules/GreyWarden` 文件夹。
2. 将压缩包中的完整 `GreyWarden` 文件夹解压到游戏 `Modules` 目录。
3. 在启动器中启用 `GreyWarden`。

旧档可以继续使用。更新时请替换完整模组，不要只覆盖部分文件。
1.4.5 已实机验证，1.4.6 已完成接口交叉构建，1.4.7 是日常测试基准。

## 更新日志

### 2026-07-26 v1.4-r8

相较 `v1.4-r7`：

#### 新增与调整

- 重复被捕会逐次提高震慑强度和最低恢复等级；第一次仍可完全恢复，长期累犯最终会停留在最高压制。震慑特殊问候改为概率触发。
- 悬赏、赎罪任务日志和人物百科的案底详情现在使用可点击的地点名称，可直接打开对应定居点百科。
- 普通承办队与协力军团都能派出高速骑兵截击队；追击速度按部队正常构成推算，不再受临时地形或状态干扰。
- 灰袍三条精锐升级路线采用相同选择权重。无封地灰袍也会出售超出本队需要的缴获船只。

#### 修复

- 修复调兵订单在练兵官没有指定兵种时立即报错，以及备齐士兵后继续升级而再次缺货的问题。
- 调兵缺货时，练兵官会与其他灰袍领主在同一地点完成真实换兵；一支部队不足时会继续寻找下一支。
- 修复人物百科“案底与震慑”详情打开时报错；界面恢复原版小弹窗外观，同时保留正文地点链接。

### 2026-07-25 v1.4-r7

相较 `v1.4-r6`：

#### 新增与调整

- 新增练兵换防、三路精锐兵种树、真实调兵与封地申诉；加入或重新加入灰袍会获得黑曜指挥官盾。
- 英雄百科新增震慑预计恢复时间，震慑持续更久。
- 协力军团会评估目标与附近援军、持续补充可用领主；全部力量仍不足时会结束案件并恢复和平。
- 灰袍会根据现场战力和追捕速度选择集合、分散或派骑兵先行截击。

#### 修复

- 修复弱势领主不求援、协力队伍无法会合、高速目标拖慢军团和案件迟迟不交战的问题。
- 修复罪犯躲入定居点、堵在城门或依附其他军团造成的长期僵局。
- 修复承办领主战败后的案件和空军团残留，以及相关崩溃。
- 修复练兵官与贵族事务协调官被普通对话或其他任务打断、反复拦截玩家和交接后误入战斗的问题。
- 修复封地申诉提前裁定、玩家无法投票或追加支持无效的问题。
- 修复玩家因灰袍追捕同国罪犯而被连带扣除声望、罚款的问题。
- 纠察队会在接近后主动交谈；修复从城堡发起野外切磋后返回时可能崩溃的问题。
