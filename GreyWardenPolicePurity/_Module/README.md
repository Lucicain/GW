# GreyWarden（灰袍守卫）

支持游戏本体：`Mount & Blade II: Bannerlord 1.4.7`

本模组加入灰袍守卫家族、专属兵种和一套动态执法玩法。玩家的守法或犯罪行为会影响灰袍声望，并决定后续的奖励、悬赏、追捕与处罚。

## 安装

1. 删除旧的 `Modules/GreyWarden` 文件夹。
2. 解压新版，将完整的 `GreyWarden` 文件夹放入游戏 `Modules` 目录。
3. 在启动器中勾选 `GreyWarden`。

本次更新兼容旧存档，无需重新开档。请勿只覆盖部分文件。

## 最近更新

### 2026-07-16 v1.4.7-r2

#### 新增与调整

1. 灰袍兵种和领主会在近身战斗中主动使用踢击或盾击，兵种等级越高，击倒能力越强。
2. 灰袍大型盾牌现在可以在未举盾或背负时挡住真正经过盾面的敌方近战攻击。
3. 灰袍使用踢击或盾击时，大型盾牌会继续提供正面保护。
4. 灰袍重步兵移除长矛，改用帝国军团步兵的短锤；灰袍骑士仍保留骑枪。
5. 灰袍兵种与领主技能改用对应的帝国精锐模板，不再使用过高的全技能数值。
6. 所有灰袍人类单位的有效生命值调整为原版的 `1.5` 倍。

关键数值：踢击与盾击冷却 `3` 秒；一级、二级、三级灰袍及领主的击倒率分别为 `40% / 60% / 80%`；大型盾牌被动挡击时承受 `3` 倍耐久损耗。

#### 修复

1. 修复自定义战斗载入灰袍兵种或领主时可能无法进入战斗的问题。
2. 修复黑金盾可能导致游戏退出报错的问题。
3. 修复部分安装包中只有黑金盾、其他灰袍装备不显示的问题。
4. 修复黑金盾远距离模型缺失的问题，现在会根据距离切换简化模型。

## 当前可玩内容

### 灰袍声望与执法

- 声望范围为 `-100～100`。
- 守法、保护村民和商队可以提高声望；袭击平民、商队或劫掠村庄会降低声望。
- 声望 `-1～-10` 时，灰袍纠察队会要求缴纳罚金或接受调查。
- 声望低于 `-10` 时，灰袍正式警察会通缉并追捕玩家。
- 玩家可以缴纳罚金、接受赎罪任务，也可以拒绝执法并与灰袍交战。

### 守法奖励

- 正声望可以领取村民酬谢。
- 声望达到 `20` 后可以加入悬赏猎人玩法。
- 高声望可以向灰袍领主征调专属兵种，并在劣势野战中获得灰袍增援。

### AI 执法与震慑

- 灰袍会追捕实施焚村、袭击村民或袭击商队的 AI 领主。
- 被灰袍多次执法的领主会受到震慑，减少继续犯罪的倾向。
- 人物百科可以查看领主当前的灰袍震慑状态。

### 灰袍家族与兵种

- 包含灰袍轻步兵、重步兵、弓箭手和骑士，以及六名灰袍领主。
- 灰袍家族保持独立，不会被 AI 王国正常招募。
- 灰袍会在被焚毁的村庄进行善后，并可能收养幸存者作为家族后继者。
