# GreyWarden / 灰袍守卫

灰袍为《骑马与砍杀 II：霸主》加入一个源于帝国教会的独立修会。她们将保护平民、追捕劫掠者视作信仰的职责。六名灰袍领主在大地图上带队办案、救济村庄并培养后继者，村中的教士与教众为修会提供兵员和供给。玩家既可能因犯罪受到追捕，也可以赢得信任、加入灰袍并接受委托。

本包为本地玩家版 v1.4-r15（2026-10-16），适用于 Bannerlord 1.4.8，供试玩与反馈。运行所需的最新美术已包含，不含美术源文件与编辑器目录。使用 1.5.2 的玩家请选择此前发布的 v1.5-r1。
English: README_EN.md

## 主要内容

- 灰袍领主会各自带队处理练兵、商路保护、乡土保护、地方请求、村庄重建和玩家事务，成年后继者会继承仍然存在的职责。
- 灰袍会记录袭击商队、攻击村民和劫掠村庄等犯罪，按职责和距离追捕目标；强敌会引来协力军团，过快的目标可能遭到骑兵截击。
- 案件总卷会显示未结案件、承办队伍和司法公库。被捕领主会留下案底并受到逐渐恢复的震慑，累犯会受到更强的长期压制。
- 玩家可通过保护平民和协助办案提高声望并加入灰袍，随后领取悬赏、订购士兵、获得战场支援、村民酬谢与封地申诉资格。
- 灰袍会通过真实会合换防和交付士兵，处理地方请求、重建被毁村庄，并管理案件收入、行动支出和海战船只。
- 模组包含灰袍兵种树、黑金装备、自带战斗效果的灰袍武器、灰袍战马、专属盾牌、双持剑、踢击、盾击、被动大盾防护，以及与灰袍领主切磋的内容。灰袍在战场上死战不退，并有专属的战场配乐。

- 灰袍声望达到 20 后会收到雇佣邀请。接受雇佣后才能使用队内灰袍士兵的派遣对话；接新委托还需保持足够声望并穿着灰袍指挥官套装。
- 玩家受托办案可交涉、收缴钱货、押送犯人，也能派遣士兵求援或代为交差。私留办案所得与过度执法可能引来后续调查。

## 本次玩家版内容

相较正式版 v1.4-r14（2026-10-07替换包）：

- 灰袍教士可在村庄传教，召集教众守村，并举行布道集会与火刑。仪式期间会显示配图、声音和村庄烟雾。
- 教众会向修会捐献钱货，接收俘虏与装备，维护村中军械。祭司在村中站稳后，守村队会像民兵一样逐渐壮大。
- 灰袍部队和信众村都有军械库，按资历从高到低给灰袍士兵发放缴获的武器护甲：资深士兵只补齐空缺，新兵和狂信者会换上更好的装备。士兵用不上的马匹、披风等不进军械库，会被拿去出售。
- 村庄之间会派出传教队与运械队，多余货物由货队运到城镇出售。玩家可在途中与这些队伍交谈、购买货物。
- 灰袍领主会到村庄补充兵员（先招守村队里资历浅的士兵）、交付物资和照料伤员。练兵领主手下老兵较多时，会派运兵队把老兵和多余军械送进村子充实守备。
- 灰袍领主队伍里的其他士兵会按等级转为相应的灰袍士兵，原有装备交进军械库。
- 灰袍接案后可派使者前往谈判，再决定后续追捕；对方可能交钱、请求宽限、提出比武或随使者投案。
- 新档开局时与灰袍领主关系极好。满足结婚条件时，可直接向任意成年灰袍领主求婚；求婚对象是族长时，修会会先安排新的族长接任。嫁给你的灰袍领主仍保有灰袍领主的战斗能力。
- 灰袍领主无论拿什么武器、盾牌、坐骑，都能发挥灰袍装备的战斗效果；自定义战斗中的灰袍指挥官同样适用。她们濒死时会以残血坚持片刻，这段时间里击倒敌人便能恢复生命；击杀敌人也会让她们在战斗中越战越强。
- 统一修会、教士、教众的介绍和对话，改写村庄菜单与地图提示。五位创始领主使用新的外貌，族长保留原貌；六位创始领主有了各自的声音与性格。
- 灰袍家族换上黑底金鸟的新旗帜。灰袍战马有了多种毛色。
- 更新头盔面罩位置与衣物布料资源。
- 改进协力军团，减少反复组建和解散；改进临时队伍归队、借船及伤兵和经验交接，回到陆地的分队会先并回领主队伍。同一版本中存档读回后，进行中的差事应继续接上。
- 修复声望为负时的赎罪任务：目标可以正常谈判，灰袍使者不再插手同一案件，处理后可以交差。

试玩可以重点留意：村庄是否发展自然、使者谈判是否清楚、灰袍是否过强或过弱，以及哪些文字仍然难懂。遇到问题时，记录当时在做什么和相关人物、地点即可。

## 已知问题

- 村中守兵不足两人、尚未形成民兵队时，归队士兵的伤情与剩余经验可能无法完整保留。
- 曾出现退出游戏时崩溃，原因尚未查明；本玩家包是否会复现仍待反馈。
- 游戏中途偶尔会无提示闪退，原因仍在排查。遇到时请告诉我们当时在做什么。
- 村庄与军械内容较多时的流畅度仍需观察。

## 安装与更新

1. 删除旧的 Modules/GreyWarden 文件夹。
2. 将压缩包中的完整 GreyWarden 文件夹解压到游戏 Modules 目录。
3. 在启动器中启用 GreyWarden。

本版请开新档。版本之间不兼容；更新时请替换完整模组，不要只覆盖部分文件。

## 更新日志

### 2026-10-07 v1.4-r14（Bannerlord 1.4.8）

相较 v1.4-r13：

#### 新增与调整

- 大地图左下角的按钮栏新增「灰袍事务」按钮，位于家族与王国之间。加入灰袍后点它即可打开灰袍事务；尚未加入时按钮不可用。
- 加入或重新加入灰袍时发放的装备，每件都带最好的品质。
- 使者押着普通俘虏时，会先去最近的城镇把人卖掉，卖完再接着送信，并告诉你卖了多少钱。
- 使者押送的犯人不会在路上逃脱。
- 队伍里有带案底的同伴时，灰袍会就这名同伴本人的案子来找你，你可以替他缴清罚金结案；他的案子不会算到你头上，也不会被反复拦截。
- 去投奔军团途中被你拦下的承办目标，不会再仗着整个军团的兵力拒绝谈话；谈不拢时的回绝台词不再提具体日期。

#### 修复

- 灰袍保持独立，不再加入其他国家、成为佣兵或另建王国。
- 读档时，已加入其他国家的灰袍会退出该国及其军团，恢复独立。
- 搭配 RBM 游玩时，灰袍领主不会再进城自动换掉原有装备。

- 在战后界面请灰袍调停后，游戏可能崩溃。
- 灰袍有时会对同一个兵力不足的案子反复接手又放弃。
- 读档后，灰袍的协力军团无法再吸收成员，解散时出错。
- 活捉委托目标后立刻去交差，交差界面里看不到俘虏，要先在地图上走一段才行。
- 使者押着俘虏时可能舍近求远，去很远的城镇卖人，没走到又折回，来回绕路。
- 使者或灰袍临时队伍借走的船，有时没有还回原主。

### 2026-09-25 v1.4-r13（Bannerlord 1.4.8）

相较 v1.4-r12：

#### 新增与调整

- 新增灰袍战场配乐：任意一方的普通士兵有一半以上是灰袍时，战斗改用辛迪加风格的分段配乐，乐曲强弱随战况起伏。
- 灰袍在战场上死战不退：士气照常起落，但不会溃逃。
- 战场支援改为三次机会：本方兵力跌到开战时的两成、一成和只剩最后一人时各判定一次，成功一次即止。支援规模按敌方剩余兵力决定，灰袍声望越高，支援越容易到、来得越多。战场上的灰袍士兵和灰袍领主也能等到支援，不论他们站在哪一边；自定义战斗中以灰袍身份出战同样有效。
- 灰袍兵种整体提高一阶；每名士兵出场时穿戴同一套完整装备，不再东拼西凑。
- 灰袍武器自带战斗效果，谁拿谁有：灰袍单手剑、钉头锤、双手剑和骑枪有机会击倒、打下马或破开武器招架；双刀击倒更频繁；灰袍穿刺箭能击倒步行的敌人，打盾伤害加倍；灰袍大盾更耐打。
- 灰袍重步兵改用新的灰袍卡拉德钉头锤，灰袍弓箭手改用新的灰袍穿刺箭。
- 灰袍骑士改为骑枪配双手剑，不再带单手剑和盾；骑枪更长，下马后也能架枪。
- 灰袍骑士改骑新的灰袍战马：冲撞更容易撞飞、撞倒步兵，不容易受惊人立，挨小伤不受影响；骑手受到的伤害由人和马各担一半。任何人骑上灰袍战马都有这些效果。
- 玩家和灰袍弓箭手的双刀改用同一把副刀。
- 踢击、盾击和射箭在本场战斗中积累的技能加成设有上限。
- 灰袍派出的各类临时队伍和你派出的使者都不再需要口粮，长期在外也不会挨饿。
- 派使者不再需要准备口粮和盘缠。使者身上押有俘虏时，会顺路进城卖掉。
- 灰袍的临时队伍会向灰袍领主借船，你的使者会向你借船，都能渡海；你在海上又没有多余的船时，不能派出使者。
- 在野外击溃委托目标即可回去复命，领取全额办案费；把人押来交给灰袍，还会另得一笔赎金。
- 练兵随行队伍在练兵官打仗、随军团出征时也会一直跟着他。
- 从灰袍领主队里调出去的截击队，原领主战败或被俘时，会把人交给最近的灰袍领主，不再流失。

#### 修复

- 练兵订单可能永远凑不齐、无法交付：随行队伍里混进其他兵种或外来士兵后占满名额。现在这些人会被退回，名额由订单兵种补上。
- 随行练兵队会把一部分士兵练成订单以外的兵种。
- 账簿显示的练成人数与实际能交付的人数不一致。
- 随行练兵队和使者长时间在外会饿伤减员。
- 击溃委托目标后，有时被误判为目标已被别人了结，只能领辛苦费。
- 帮灰袍打仗惹上的战争，有时找灰袍领主时没有调停选项。
- 骑兵冲进灰袍弓箭手群时，游戏可能崩溃。
- 灰袍弓箭手拔出双刀后迟迟换不回弓。
- 灰袍大盾被动挡下攻击时仍会掉血并出现硬直。
