# GreyWarden / 灰袍守卫

灰袍守卫为《骑马与砍杀 II：霸主》加入一个会在大地图上真实办案的独立执法家族。六名灰袍领主会侦查犯罪、追捕领主、组织协力军团、救济村庄并培养后继者。玩家既可能因犯罪受到追捕，也可以赢得信任、加入灰袍并接受委托。

本次发布提供两个安装包，内容完全相同，只是支持的游戏版本不同：v1.5-r1 对应 Bannerlord 1.5.2，v1.4-r10 对应 Bannerlord 1.4.8。请按自己的游戏版本选择，装错版本会在启动时提示模组无法加载。
English: README_EN.md

## 主要内容

- 灰袍领主会各自带队处理练兵、商路保护、乡土保护、地方请求、村庄重建和玩家事务，成年后继者会继承仍然存在的职责。
- 灰袍会记录袭击商队、攻击村民和劫掠村庄等犯罪，按职责和距离追捕目标；强敌会引来协力军团，过快的目标可能遭到骑兵截击。
- 案件总卷会显示未结案件、承办队伍和司法公库。被捕领主会留下案底并受到逐渐恢复的震慑，累犯会受到更强的长期压制。
- 玩家可通过保护平民和协助办案提高声望并加入灰袍，随后领取悬赏、订购士兵、获得战场支援、村民酬谢与封地申诉资格。
- 灰袍会通过真实会合换防和交付士兵，处理地方请求、重建被毁村庄，并管理案件收入、行动支出和海战船只。
- 模组包含灰袍兵种树、黑金装备、专属盾牌、双持剑、踢击、盾击、被动大盾防护，以及与灰袍领主切磋的内容。

## 安装与更新

1. 删除旧的 Modules/GreyWarden 文件夹。
2. 将压缩包中的完整 GreyWarden 文件夹解压到游戏 Modules 目录。
3. 在启动器中启用 GreyWarden。

既有战役存档可以继续使用。更新前正在进行的旧悬赏不做衔接，请先结案。更新时请替换完整模组，不要只覆盖部分文件。

## 更新日志

### 2026-08-31 v1.5-r1（Bannerlord 1.5.2） / v1.4-r10（Bannerlord 1.4.8）

两个安装包内容相同，下面的改动同时适用于两者。相较 v1.4-r9：

#### 新增与调整

- 同时提供 Bannerlord 1.5.2 与 1.4.8 两个安装包，两者玩法内容一致，均兼容 NavalDLC 的海战与自定义战斗入口。
- 新增独立兵种「灰袍守护者双刃卫士」：双持一对灰袍双刀、不带弓箭，由轻步兵升级而来，与重步兵同级。灰袍弓箭手保持纯远程。
- 双刃卫士与电脑控制的灰袍武将都会真正双持作战，左手刀同样造成伤害，并按兵种等级触发灰袍击倒。
- 玩家加入或重新加入灰袍时会获赠一对双刀。四向格挡、攻击动作与移动衔接与 AI 共用同一套，不需要额外模组；左手挥砍命中时，即使对方正在防御也可按灰袍规则触发击倒。
- 双刀可以从地面拾取，但不会出现在锻造界面或城镇锻造订单中，无法由玩家打造。
- 亲手击败仍在案罪犯的部队会积累灰袍声望，与剿匪、救援一样按亲自击倒人数累计，开局多了一条提升途径。
- 灰袍家族页的两个按钮合并为一个「灰袍事务」：对外战争与开战依据、案件与差事总池、司法公库、你的声望、家族名册都在同一页。声望不再只在变动瞬间飘一次字，随时可以查看；处于通缉状态时会一并列出巡逻队与灰袍领主各自的罚金数额。
- 自定义战斗将灰袍指挥官列为第一项，同时保留原版指挥官选项；武将预览使用各自完整的人物与装备数据。
- 所有灰袍武器、护甲、盾牌和马铠改用原版非商品机制，不会由城镇市场自动刷新，也不进入常规装备战利品。
- 灰袍常驻队伍不再凭空获得船只，海战船只由原版经济自行购置，公库不再因此快速膨胀。
- 案件结案后灰袍会立即与不再有执法理由的势力恢复中立；协助灰袍缉捕本国罪犯后，灰袍不会在战斗结束后立刻转身攻击玩家。
- 灰袍重步兵保留剑盾并作为独立终阶兵种，不再额外携带小锤。

#### 修复

- 修复站在村庄里被无辜扣声望的问题。此前只要村庄正在被劫掠、而玩家的目的地正是这座村庄（收税、办差、驻留都算），这次劫掠就会算到玩家头上，扣除声望并留下案底。现在只有真正动手劫掠的一方才会被追究。
- 修复缴清罚金后仍被视为通缉的问题。声望恢复到 0 或以上时，灰袍不会再拦下玩家索要 0 第纳尔的罚金，遗留的追捕任务也会自动撤销。
- 修复重度通缉时灰袍领主已经追到玩家身边却不进入执法对话的问题；现在会正常打开缴纳罚金、赎罪或拒捕选项，认罚或缴款后完整结束本次会面。
- 修复纠察队只前往玩家旧位置的问题；纠察队现在会持续跟随玩家的实时位置，在接触范围内正常发起会面。
- 修复游戏更换版本后 GreyWarden 无法加载、启动时直接报错的问题；现在 1.5.2 与 1.4.8 各有对应的安装包。
- 修复自定义战斗在界面初始化和兵种预览阶段崩溃闪退的问题。

### 2026-08-05 v1.4-r9

相较 v1.4-r8：

#### 新增与调整

- 悬赏通知现在提供最近、较难和较简单三份契约，赏金按接单时的难度固定，不再按人数计算。
- 玩家接手悬赏后会主导行动。灰袍队伍护送玩家，接近目标时按玩家的决定宣战，必要时仍会派出高速骑兵截击。
- 目标落败后可向任意灰袍领主领奖；五日内未领奖时，结算队会主动前来付款并返回附近驻地。
- 悬赏统一为四十五日，目标落败后立即结束护送，任务和结算队状态可跨存档继续。
- 练兵官换防时会按本队精锐兵种比例派兵。GreyWarden 单独启用时不再阻止原版成就。

#### 修复

- 修复人物与家族百科按钮缺失、挤压原版页面或地点链接失效的问题；灰袍入口现在直接加入原版百科页面。
- 修复只启用 GreyWarden 时因运行组件缺失而无法进入战役的问题。
- 修复玩家接手协力悬赏后灰袍仍自行追捕、无法及时宣战或不再派出截击队的问题。
- 修复悬赏超时、待领奖倒计时、护送和战争状态清理异常的问题。
- 修复战后获救士兵和返队截击兵造成超编与精锐损失的问题。
