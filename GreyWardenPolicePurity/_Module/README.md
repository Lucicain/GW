# GreyWarden / 灰袍守卫

灰袍守卫为《骑马与砍杀 II：霸主》加入一个会在大地图上真实办案的独立执法家族。六名灰袍领主会侦查犯罪、追捕领主、组织协力军团、救济村庄并培养后继者。玩家既可能因犯罪受到追捕，也可以赢得信任、加入灰袍并接受委托。

当前开发版本适配 Bannerlord 1.5.2 测试版；旧版游戏请使用与其版本对应的 GreyWarden。
English: README_EN.md

## 主要内容

- 灰袍领主会各自带队处理练兵、商路保护、乡土保护、地方请求、村庄重建和玩家事务，成年后继者会继承仍然存在的职责。
- 灰袍会记录袭击商队、攻击村民和劫掠村庄等犯罪，按职责和距离追捕目标；强敌会引来协力军团，过快的目标可能遭到骑兵截击。
- 案件总卷会显示未结案件、承办队伍和司法公库。被捕领主会留下案底并受到逐渐恢复的震慑，累犯会受到更强的长期压制。
- 玩家可通过保护平民和协助办案提高声望并加入灰袍，随后领取悬赏、订购士兵、获得战场支援、村民酬谢与封地申诉资格。
- 灰袍会通过真实会合换防和交付士兵，处理地方请求、重建被毁村庄，并管理案件收入、行动支出和海战船只。
- 模组包含灰袍兵种树、黑金装备、专属盾牌、双持剑、踢击、盾击、被动大盾防护，以及与灰袍领主切磋的内容。

## 安装与更新

1. 删除旧的 Modules/GreyWarden 文件夹。
2. 将压缩包中的完整 GreyWarden 文件夹解压到游戏 Modules 目录。
3. 在启动器中启用 GreyWarden。

既有战役存档可以继续使用。更新前正在进行的旧悬赏不做衔接，请先结案。更新时请替换完整模组，不要只覆盖部分文件。

## 更新日志

### 2026-08-30 v1.4-r11（开发中）

相较 v1.4-r10：

#### 新增与调整

- 灰袍家族页原有的「宣战详情」与「案件总卷」两个按钮合并为一个「灰袍事务」。原先两处显示的是同一批案件信息，现在对外战争列在最上方，每条只说明是哪个势力、依据是什么，案件细节看下方对应的案件行，不再重复。
- 灰袍事务新增「你的声望」一栏：当前声望值、所处区间（声誉良好／尚无记录／已有嫌疑／通缉中），通缉时一并列出巡逻队与灰袍领主各自的罚金数额。此前声望只在变动瞬间飘一次字，事后无处查看。
- 家族名册（人数、收养冷却、上次收养）从宣战详情移入灰袍事务，与司法公库、声望并列。
- 当前开发版适配 Bannerlord 1.5.2 测试版，保留原有战役、战斗和双刀玩法。
- 重新加入独立兵种「灰袍守护者双刃卫士」：装备一对双刀、不带弓箭，由轻步兵升级而来，与重步兵同级。
- 双刃卫士在战场上真正双持作战：左右手动作与玩家一致，左手刀同样造成伤害并按兵种等级触发灰袍击倒。弓箭手保持纯远程。
- 由电脑控制的灰袍武将同样会双持作战，与双刃卫士使用同一套机制。
- 自定义战斗恢复灰袍指挥官覆盖与完整灰袍兵种、装备注册。
- 自定义战斗将灰袍指挥官列为第一项，同时保留原生指挥官选项；武将预览使用各自完整的人物和装备数据。
- 双刀回到只有玩家角色可以使用，与本模组一直稳定可用的形态一致；灰袍弓箭手恢复为普通远程兵种，重新配备贵族长弓、穿甲箭与灰袍单手剑。
- 移除让士兵使用双刀的全部内容，包括专为士兵新增的双刀动作资源。此前正是这部分内容导致百科与自定义战斗的人物模型不显示或姿态异常，且会波及原版兵种。
- 双刀保留与灰袍单手剑一致的外观，全部使用本模组自己的物品配置，不加载 ROT 或其他外部模组资源。

#### 修复

- 修复站在村庄里被无辜扣声望的问题：此前只要村庄正被劫掠、而玩家的目的地正是该村（收税、办差、驻留都算），系统就会把这次劫掠算到玩家头上并扣除声望、留下案底。现在只有真正动手劫掠的一方才会被追究。
- 修复缴清罚金后仍被视为通缉的问题：声望已恢复到 0 或以上时，灰袍不会再拦下玩家索要 0 第纳尔的罚金，遗留的追捕任务会自动撤销。
- 修复携带双刀的角色进入水体导致游戏退出的问题，玩家、双刃卫士与灰袍武将一并覆盖；双刀角色现在可以正常游泳与潜水，进出水域不会被强制收刀，战斗表现与陆地上完全一致。
- 修复 1.5.2 更换伤害模型接口后模组无法编译、启动器提示不兼容的问题。
- 修复自定义战斗在界面初始化和兵种预览阶段发生崩溃闪退的问题，恢复稳定进入。
- 修复双刀专用模板失效及公共武器处理对百科和自定义战斗预览的干扰；两处预览现在直接使用灰袍角色的真实人物、护甲、坐骑和双刀装备，不再替换成展示用剑盾。
- 针对启用 NavalDLC 时的自定义战斗入口，补齐独立角色列表接入；灰袍武将仍排在第一项，原生指挥官选项保持不变。

### 2026-08-28 v1.4-r10

相较 v1.4-r9：

#### 新增与调整

- 亲手击败仍在案罪犯的部队会积累灰袍声望，与剿匪、救援一样按亲自击倒人数累计，开局升级多了一条可行路径。
- 所有灰袍武器、护甲、盾牌和马铠均使用原版非商品机制，不会由城镇市场自动刷新，也不进入原版常规装备战利品；玩家持有和卖出不受额外脚本干预。
- 灰袍常驻队伍不再凭空获得船只，海战船只改由原版经济自行购置，公库不再因“免费发船后再出售”快速膨胀。
- 案件结案后灰袍会立即与不再有执法理由的势力恢复中立，协助灰袍缉捕本国罪犯后，灰袍不会在战斗结束后立刻转身攻击玩家。
- 灰袍重步兵保留剑盾装备并作为独立终阶兵种；弓箭手同时配备弓箭和双刀，不再额外开设双刃卫士兵种。
- 重步兵不再额外携带小锤，自定义战斗专属指挥官使用原版剑盾配置。
- 玩家和 AI 共用同一套双刀、四向近战格挡、攻击动作与移动衔接，不需要启用 ROT；左手挥砍命中即使对方正在防御也可按灰袍规则触发击倒。玩家加入或重新加入灰袍时会获赠一对。
- 弓箭手使用双刀时，左右手挥砍、上挥、下劈和突刺均可按灰袍规则触发击倒；踢击与盾击仍保持各自的原版兼容判定。
- 双刀不会出现在锻造界面或城镇锻造订单中，不能由玩家打造；玩家的正式获取途径是加入或重新加入灰袍时获赠。
- 双刀专用动作现在作为独立资源，只分配给战场中实际携带完整双刀的玩家与 AI；百科、自定义战斗和普通英雄展示只加载原版人物动作。
- AI 双刀不再修改全局 Agent 或武器数据方法；资格数据只在真实战场人物完成生成时写入该名 AI 的现有副手，避免影响百科和自定义战斗展示人物。

#### 修复

- 修复重度通缉时灰袍领主已经追到玩家身边却没有进入执法对话的问题；现在会正常打开缴纳罚金、赎罪或拒捕选项，并限制重复接触。认罚或缴款后会完整结束本次会面，不会再次弹出同一对话。
- 修复纠察队追捕时只前往玩家旧位置的问题；纠察队现在会持续跟随玩家的实时位置，在接触范围内正常发起会面。
- 玩家案件现在以正常执法欲望参与灰袍领主的原版决策；欲望胜出后会直接追踪玩家的实时位置，不再先赶往旧坐标。
- 修复升级 Bannerlord 1.4.8 后因游戏接口变更导致 GreyWarden 无法加载、启动时直接报错的问题。
- 修复首版双持资源加载顺序不完整、导致游戏在读取动作文件时无法启动的问题。
- 修复左手剑被当作普通主手武器生成，导致剑不可见、双持后无法攻击或防御的问题。
- 修复新开沙盒时城镇锻造订单抽中双刀专用模板、导致战役创建阶段直接报错退出的问题。
- 修复从地面拾取双刀时直接退出的问题；两把刀现在会按任意拾取顺序进入正确装备格，凑齐后再安全拔出。
- 修复加入双刀地面拾取后，百科士兵和自定义战斗人物预览再次不显示或姿态异常的问题；两种拾取顺序继续保留。
