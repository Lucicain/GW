# GreyWarden / 灰袍守卫

统一适配 **Mount & Blade II: Bannerlord 1.4.x（1.4.5、1.4.6、1.4.7）**，不设置游戏修订号硬限制。
英文版：[README_EN.md](README_EN.md)

## 安装

1. 删除旧的 `Modules/GreyWarden` 文件夹。
2. 将新版完整 `GreyWarden` 文件夹解压到游戏 `Modules` 目录。
3. 在启动器中启用 `GreyWarden`。

旧档可以继续使用。更新时请替换完整模组，不要只覆盖部分文件。

## 兼容入口

- 统一入口就是 `Bannerlord 1.4.x`；1.4.5、1.4.6、1.4.7 使用同一个安装包，不需要选择分支版本。
- 1.4.5 已实机验证，1.4.6 已通过完整接口交叉构建，1.4.7 是开发与日常测试基准。

## 最近更新

### 2026-07-22 v1.4-r6

相较 `v1.4.7-r5`：

#### 新增与调整

- 六名初始领主开始分工办案，优先追查商队犯罪、乡土犯罪、地方请求或重建村庄；本职工作告罄后也会协助其他案件。
- 新增烧毁村庄重建和原版城镇、村庄请求。灰袍会亲自抵达并停留处理，完成后为当地带来少量发展。
- 商队犯罪与侵害村庄现在分别震慑；玩家以灰袍受托身份结案，也会对罪犯、族人和目击者产生同类效果。
- 案件池现在收纳普通、协力、玩家、收养、重建与地方请求；有人承办的案件可以持续获得支援，成功结案会得到司法公库拨款。
- 灰袍村庄收入降低，重建会消耗公库资金；案件总卷可以直接查看当前公库余额。
- 玩家可以接受使者邀请加入灰袍，也可以退出并在更高声望下申请重新加入；悬赏、调兵和增援都要求有效身份与足够声望。
- 发行入口统一为 Bannerlord 1.4.x，同一安装包覆盖 1.4.5、1.4.6 与 1.4.7。

#### 修复

- 修复招募使者缺粮、追不上玩家、谈话后反复拦截等问题；使者和和平结案的纠察队都会正常返城后解散。
- 修复无领主支援队交谈崩溃、军团长期僵持以及支援不足时案件无法推进的问题。
- 修复人物百科姓名、震慑说明和案件总卷部分文本难以阅读的问题。
- 修复 1.4.5 与 1.4.6 的收养事件百科接口差异，避免模组因此无法载入。

### 2026-07-20 v1.4.7-r5

相较 `v1.4.7-r4`：

#### 新增与调整

- 新增案件总卷、灰袍真实经济和原版大地图 AI 办案。
- 强敌案件可以召集灰袍军团和无领主支援，案件结束后成员会重新领取工作。
- 犯罪、被捕与震慑历史会长期保留，未结案件与历史记录分开处理。

#### 修复

- 修复办案被普通巡逻覆盖、支援队逐队送死、犯人躲入城镇以及案件错误结算等问题。

## 当前可玩内容

- 玩家加入灰袍、退出与重新申请，以及悬赏、赎罪、调兵和战场增援。
- AI 领主分类执法、案件总卷、协力军团、分类震慑与犯罪历史。
- 村庄重建、地方请求、收养后继者和可随人员死亡而断绝的职务。
- 灰袍司法公库、罚金、办案拨款、村庄收入和重建支出。
- 灰袍专属兵种、黑金盾，以及踢击、盾击和被动大盾防护。
- 与灰袍领主进行城内或野外切磋。
