# GreyWarden / 灰袍守卫

支持 **Mount & Blade II: Bannerlord 1.4.7**

英文版：[README_EN.md](README_EN.md)

## 安装

1. 删除旧的 `Modules/GreyWarden` 文件夹。
2. 将新版完整 `GreyWarden` 文件夹解压到游戏 `Modules` 目录。
3. 在启动器中启用 `GreyWarden`。

本次重做了 AI 领主的案底数据；旧档会自动迁移累计犯罪、被捕与震慑数字，并只保留尚未结案的案件。请勿只覆盖部分文件。

## 最近更新

### 2026-07-20 v1.4.7-r5

相较 `v1.4.7-r4`：

#### 新增与调整

- 灰袍家族百科新增“案件总卷”，可查看完整任务池以及案件的承办、协力和收养善后进度。
- 灰袍领主现在通过原版大地图欲望办案：任务优先于普通巡逻，但补给、招兵、疗伤、交易和安全判断仍由原版处理。
- 灰袍家族改用真实经济维持行动。领主需要自行购买粮食和招募士兵，罚款、没收物拍卖、保护费与办案经费会进入司法公库。
- 面对强敌时，承办领主会召集其他灰袍领主组成原版军团；后续无领主支援会并入军团，案件结束后成员重新领取任务。
- 所有合格的灰袍领主均可领取普通案件；玩家拒捕案件同样可以触发领主协力。
- 已结案件只长期保留累计犯罪、被捕与震慑记录，不再保存无用的事件细节。

#### 修复

- 修复灰袍军团明明总战力占优却仍无法按原版判断主动接战的问题。
- 修复外交恢复和平、短暂战斗结算或目标状态变化导致案件卡死、军团提前解散的问题。
- 修复无领主支援批量刷出、短暂交火后撤退，以及已有军团时仍逐队送死的问题。
- 修复办案行动被普通巡逻或进城行为覆盖，同时保留原版必要的后勤决策。
- 修复罪犯躲入城内造成双方长期僵持的问题；目标被驱逐后会留在城外，直到交战或案件结束。
- 修复无关战斗错误结案、旧档案件加载失败和案件总卷无法完整滚动等问题。

### 2026-07-19 v1.4.7-r4

相较 `v1.4.7-r3`：

#### 新增与调整

- AI 领主现在会永久保留累计犯罪与被灰袍抓获记录；当前未结案件与历史案底分开处理，震慑消退后也不会清除犯罪历史。
- 本人震慑与家族震慑现已分别记录。同场被俘但没有未结案件的领主只会获得目击型家族震慑，不会被记为罪犯或增加被捕次数；空闲灰袍会优先追捕距离最近的未结案领主。
- 领主谈及灰袍执法经历时，会根据本人或家族震慑、震慑程度、五项性格倾向，以及玩家是否已加入灰袍表达不同态度；仍有震慑的领主在普通交谈时会稳定触发相应开场白。
- 正义战斗中的玩家个人击杀现在会跨战斗累计，达到门槛后获得声望；犯罪战斗造成的声望扣除仍按每场战斗单独结算。

#### 修复

- 修复收养通知与百科记录缺少被收养者姓名和来源村庄的问题。
- 灰袍的案底功能现在直接附加在原版人物百科页面上，修复与 Messenger（信使）同时启用时其按钮失效的问题；灰袍本身仍不需要任何外部前置。

## 当前可玩内容

- 灰袍声望、犯罪记录、罚金、赎罪、通缉与追捕。
- 村民酬谢、悬赏任务、兵种征调与战场增援。
- AI 领主犯罪执法、案件总卷、协力军团与灰袍家族经济。
- 灰袍专属兵种、六名初始领主及后继者收养系统。
- 灰袍近战踢击、盾击、被动大盾防护及黑金盾外观。
- 与灰袍领主进行城内或野外切磋。
