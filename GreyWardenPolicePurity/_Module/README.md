# GreyWarden / 灰袍守卫

灰袍守卫为《骑马与砍杀 II：霸主》加入一个会在大地图上真实办案的独立执法家族。六名灰袍领主会侦查犯罪、追捕领主、组织协力军团、救济村庄并培养后继者。玩家既可能因犯罪受到追捕，也可以赢得信任、加入灰袍并接受委托。

同一安装包适配 Bannerlord 1.4.5 beta、1.4.5、1.4.6 和 1.4.7。
English: README_EN.md

## 主要内容

- 灰袍领主会各自带队处理练兵、商路保护、乡土保护、地方请求、村庄重建和玩家事务，成年后继者会继承仍然存在的职责。
- 灰袍会记录袭击商队、攻击村民和劫掠村庄等犯罪，按职责和距离追捕目标；强敌会引来协力军团，过快的目标可能遭到骑兵截击。
- 案件总卷会显示未结案件、承办队伍和司法公库。被捕领主会留下案底并受到逐渐恢复的震慑，累犯会受到更强的长期压制。
- 玩家可通过保护平民和协助办案提高声望并加入灰袍，随后领取悬赏、订购士兵、获得战场支援、村民酬谢与封地申诉资格。
- 灰袍会通过真实会合换防和交付士兵，处理地方请求、重建被毁村庄，并管理案件收入、行动支出和海战船只。
- 模组包含灰袍兵种树、黑金装备、专属盾牌、踢击、盾击、被动大盾防护，以及与灰袍领主切磋的内容。

## 安装与更新

1. 删除旧的 Modules/GreyWarden 文件夹。
2. 将压缩包中的完整 GreyWarden 文件夹解压到游戏 Modules 目录。
3. 在启动器中启用 GreyWarden。

既有战役存档可以继续使用。更新前正在进行的旧悬赏不做衔接，请先结案。更新时请替换完整模组，不要只覆盖部分文件。

## 更新日志

### 2026-08-05 v1.4-r9

相较 v1.4-r8：

#### 新增与调整

- 悬赏通知现在提供最近、较难和较简单三份契约，赏金按接单时的难度固定，不再按人数计算。
- 玩家接手悬赏后会主导行动。灰袍队伍护送玩家，接近目标时按玩家的决定宣战，必要时仍会派出高速骑兵截击。
- 目标落败后可向任意灰袍领主领奖；五日内未领奖时，结算队会主动前来付款并返回附近驻地。
- 悬赏统一为四十五日，目标落败后立即结束护送，任务和结算队状态可跨存档继续。
- 练兵官换防时会按本队精锐兵种比例派兵。GreyWarden 单独启用时不再阻止原版成就。

#### 修复

- 修复人物与家族百科按钮缺失、挤压原版页面或地点链接失效的问题；灰袍入口现在直接加入原版百科页面。
- 修复只启用 GreyWarden 时因运行组件缺失而无法进入战役的问题。
- 修复玩家接手协力悬赏后灰袍仍自行追捕、无法及时宣战或不再派出截击队的问题。
- 修复悬赏超时、待领奖倒计时、护送和战争状态清理异常的问题。
- 修复战后获救士兵和返队截击兵造成超编与精锐损失的问题。

### 2026-07-26 v1.4-r8

相较 v1.4-r7：

#### 新增与调整

- 重复被捕会逐次提高震慑强度和最低恢复等级，长期累犯会受到持续压制。
- 悬赏、赎罪任务和人物案底中的地点名称可以直接打开对应定居点百科。
- 普通承办队与协力军团都能派出高速骑兵截击队，追击速度按部队正常构成判断。
- 灰袍三条精锐升级路线采用相同选择权重，无封地灰袍也会出售多余的缴获船只。

#### 修复

- 修复调兵订单在练兵官缺少指定兵种时报错，以及备齐士兵后继续升级而再次缺货的问题。
- 调兵缺货时，练兵官会与其他灰袍领主真实会合换兵，并在一支部队不足时继续寻找下一支。
- 修复人物百科的案底与震慑详情打开时报错的问题。
