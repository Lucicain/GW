# GreyWarden / 灰袍守卫

灰袍为《骑马与砍杀 II：霸主》加入一个源于帝国教会的独立修会。她们将保护平民、追捕劫掠者视作信仰的职责。六名灰袍领主在大地图上带队办案、救济村庄并培养后继者，村中的教士与教众为修会提供兵员和供给。玩家既可能因犯罪受到追捕，也可以赢得信任、加入灰袍并接受委托。

本说明对应 v1.4-r16（2026-10-28），适用于 Bannerlord 1.4.8。正式玩家包包含运行所需美术，不含美术源文件与编辑器目录。使用 1.5.2 的玩家请选择此前发布的 v1.5-r1。
English: README_EN.md

## 主要内容

- 灰袍领主会各自带队处理练兵、商路保护、乡土保护、地方请求、村庄重建和玩家事务，成年后继者会继承仍然存在的职责。
- 灰袍会记录袭击商队、攻击村民和劫掠村庄等犯罪，优先处理本职类别中最近的案件。对付强敌时召集同伴；追截小队从现有士兵中抽调，优先选骑兵。
- “灰袍事务”分为我的事务、灰袍成员、职能事务、教务和军械库。可以查看承办人、使者行程和交涉回报，并在军械库整理主队装备。被捕领主会留下案底并受到逐渐恢复的震慑。
- 玩家可通过保护平民和协助办案提高声望并加入灰袍，随后领取悬赏、订购士兵、获得战场支援、村民酬谢与封地申诉资格。
- 目标躲进城镇或城堡时，可以亲自带兵进城搜捕：过卫兵这关，在领主大厅交涉、单挑或群殴，再把人押出城；也可以请灰袍派黑甲办案队随行。
- 灰袍处理地方请求、重建被毁村庄，练兵领主把健康老兵分批送往信众村。玩家调兵订单下单时付款，训练完成后由练兵领主送兵；派出的订单使者只递交订单与款项。
- 模组包含灰袍兵种树、黑金装备、自带战斗效果的灰袍武器、灰袍战马、专属盾牌、双持剑、踢击、盾击、被动大盾防护，以及与灰袍领主切磋的内容。灰袍在战场上死战不退，并有专属的战场配乐。

- 灰袍声望达到20后，招募使者会前来邀请。加入后可与队内灰袍士兵交谈并派他们办事。领取新委托还需声望达到20，并在旗帜槽装备灰袍执勤旗；卸旗暂停领取资格，已接委托继续办理。委托由玩家在事务页主动挑选，不再定期弹出招揽。
- 大地图左下角“灰袍事务”入口要求入会且声望达到20；灰袍家族百科页另有未入会也能浏览的入口。浏览不会自动入会，也不会获得接案资格。
- 职能事务中的案件优先显示，并按目标当前离玩家的距离排序。列表显示犯人与承办人；选中案件后，详情显示预计办案费、目标当前地点和兵力。预计办案费不等于罚金。
- 玩家受托办案可交涉、收缴钱货、押送犯人，也能派遣士兵求援或代为交差。私留办案所得与过度执法可能引来后续调查。
- 交涉结案、击溃目标部队或活捉目标均可复命。办案费按案件核算，活捉另付赎金；替灰袍办案引起的战争可当面或派使者请求讲和。

## 已知问题

- 曾出现退出游戏时崩溃，原因尚未查明。
- 个别领主可能因城外威胁长时间留城。
- 村庄与军械内容较多时的流畅度仍需观察。
- 周期支援尚未限定为实际停滞，长期未结案可能重复派队。
- 进城搜捕时，持械但不参战的居民逃跑前会先拔出武器；用弓箭或投掷打中守卫不会引发开战。

## 安装与更新

1. 删除旧的 Modules/GreyWarden 文件夹。
2. 将压缩包中的完整 GreyWarden 文件夹解压到游戏 Modules 目录。
3. 在启动器中启用 GreyWarden。

本版请开新档。版本之间不兼容；更新时请替换完整模组，不要只覆盖部分文件。

## 更新日志

### 2026-10-28 v1.4-r16（Bannerlord 1.4.8）

相较 v1.4-r15（2026-10-17）：

#### 新增与调整

- 新增进城搜捕：目标没有部队、躲在城镇或城堡的领主大厅时，可以接下委托，亲自带一小队士兵从城门进城。卫兵会上前盘问，可以说服他放行，也可以撤出城外，或者硬闯。
- 在领主大厅与目标交涉，谈成后押着他出城即可交差。谈崩时由双方商定单挑或群殴：有竞技场的城到竞技场单挑，没有的在清场后的大厅里决斗。
- 在城里动手就是向城主势力宣战：守军与驻军持续增援、主动追击，居民和商贩四散奔逃，必须带兵杀出城门。进出大厅时双方伤亡与街上倒下的人都会保留。
- 每宗住城案件，你有一次亲自搜捕和一次求援的机会。求援后，灰袍领主会派一支身着黑甲的办案队随你进城，选兵时单独列出、不能撤下；办案队途中覆灭会另派一支。灰袍自己也会派办案队上门，向住城的犯人收缴罚金。
- 重做“灰袍事务”：委托、订单、讲和、封地四类事务分开显示；可以在案件列表里自选委托，查看承办人、使者行程与交涉回报。封地重议可以派使者递交申请。
- 开放玩家军械库：在事务页整理主队军械，按编制留下好装备，其余退回背包。
- 军械战损改为逐人结算：只有战败时，留在战场上的库装才会被对方缴获或损毁。灰袍领主的军械随人保留。
- 正在追捕的目标会在大地图名牌上以红色标出“办案目标”。
- 介入商队、村民、劫掠和灰袍执法的战斗时，选边后先进入准备，可以返回重选或不介入，确认后才真正参战。
- 灰袍士兵也会死战不退：新兵、轻步兵、重步兵和弓箭手各有不同时长；领主的时长缩短。射击、投掷、踢击、盾击和击杀都会让灰袍在本场战斗中成长。
- 守村队超出编制的低阶兵在火刑中两人换一名更高阶的兵；练兵领主一趟把老兵送到村里；村民队专程运货进城出售。
- 灰袍先确认派得出追截队才宣战；宣战与出手前都会重新比较周边敌我强弱，双方都在城里时不新开战。
- 求援送达后，你的部队会计入灰袍一方的力量。目标被第三方扣押时，可以赎买或撤回委托。
- 约好的比武场地变成敌对、被围或叛乱时，改到另一座城。灰袍使者赶路不再设时限，途中覆灭会另派一支。
- 新档不再把你与灰袍成员的关系直接设满，灰袍与各地要人的关系也照常涨落；免费求婚保留。

#### 修复

- 修正犯人投案后原部队仍挂在军团里、可能导致游戏崩溃的问题。
- 修正上下船尚未结束时提前交接的问题；送信队与使者的海陆交接更可靠。
- 普通追截队覆灭后会继续补派；健康骑兵不足时由其他现有士兵补上。
- 重新校准战斗配乐音量。

### 2026-10-17 v1.4-r15（Bannerlord 1.4.8）

相较 v1.4-r14（2026-10-07替换包）：

#### 新增与调整

- 灰袍教士在村庄传教、召集教众守村，并举行布道集会与火刑。仪式配有图片、声音与村庄烟雾，狂信者改穿朝圣者、修士和苦修者的服装。
- 教众捐献钱货，接收俘虏与装备，维护村中军械。祭司站稳后，守村队逐渐壮大，灰袍领主可在村里补兵、交付物资和照料伤员。
- 村民队按村庄教众比例补充灰袍士兵，并从守村队调入精锐。村庄间可转运士兵、俘虏和军械，多余货物随村民队进城出售。
- 军械库按资历从高到低发装；轻步兵及以上保留原有装备、只补空位，新兵和狂信者可换上更好的装备。多余的马匹、披风和装备拿去出售。
- 练兵领主会分批把健康的满级老兵及多余军械送进村庄，补充守备。
- 灰袍接案后先派使者交涉，对方可交钱、请求宽限、提出比武或随使者投案。已出发的使者会把交涉办完。
- 罪责跟随犯人保留；被别人击败、俘虏或暂时失去部队不会抹去案底，重新出现后仍会被追责。
- 遇到强敌时，灰袍优先召集能及时赶来的同伴。主办跟随犯人、同伴前来会合，附近敌军过强时等待出手机会；对方进城后可继续跟进城内。
- 信众越多的村庄越不容易成为劫掠目标，灰袍带来的震慑仍然生效。
- 领取新委托改为装备灰袍执勤旗。装备时显示灰袍黑金家徽，卸下恢复原徽；「灰袍事务」中可主动领取委托。退出归还旗帜，重新加入只补发旗帜，不再重复发整套装备。
- 灰袍领主在城镇、城堡会面时改穿修士常服。五位创始领主更新外貌，族长保留原貌，六人各有不同声线与性格。
- 灰袍领主使用普通武器、盾牌和坐骑也能发挥灰袍战斗能力，竞技大会中的实际战斗同样适用。
- 灰袍家族换上黑底金鸟旗帜，执勤旗采用帝国仪仗旗外形；战马增加毛色，头盔面罩位置与衣物布料更新。
- 统一修会、教士、教众的介绍和对话。约好的比武、已接的地方事务与救济差事会依次办理，暂停后可继续完成。

#### 修复

- 声望为负时的赎罪任务可以正常谈判与交差，灰袍使者不再插手玩家已接手的同一案件。
- 临时队伍归队、借船以及伤兵和经验交接更可靠。
