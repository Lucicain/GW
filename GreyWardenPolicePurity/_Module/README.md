# GreyWarden / 灰袍守卫

支持 **Mount & Blade II: Bannerlord 1.4.7**

英文版：[README_EN.md](README_EN.md)

## 安装

1. 删除旧的 `Modules/GreyWarden` 文件夹。
2. 将新版完整 `GreyWarden` 文件夹解压到游戏 `Modules` 目录。
3. 在启动器中启用 `GreyWarden`。

兼容旧存档，请勿只覆盖部分文件。

## 最近更新

### 2026-07-18 v1.4.7-r3

#### 新增与调整

- 新增完整中英文支持；英文姓名采用古英语风格，中文保留原有姓名。
- 新增与灰袍领主切磋：城内使用原版竞技场双人决斗，双方穿自己的装备徒步入场，并保留观众与欢呼；野外则由双方部队列阵观战，可选择骑战或步战，没有坐骑时对方会送来一匹可用的马。
- 野外切磋会沿地图作者规划的路线选择低处作为会面点和双方阵线，保留约百米阵间距离与完整横向战场；部队正面最多铺开百米，原版阵型会绕开岩石等障碍并利用其余位置，人数过多时增加纵深。
- 重新平衡灰袍兵种，移除额外生命优势并降低部分初始属性；灰袍会在战斗中通过踢击、盾击和弓箭逐步精进武艺。

#### 修复

- 完善城内与野外切磋的列阵、交互、下马、借马、坐骑保留、观战、胜负判定及赛后对话流程；城内决斗结束后由玩家按 Tab 离场，再进入当地或附近城镇、城堡的领主大厅对话。
- 修复复杂地形中切磋地点偏离道路、战场或部队正面被障碍错误缩窄、双方行军距离失衡、兵种前后分散、将领被纵深阵型堵住，以及地形误判取消切磋的问题。
- 玩家不再被灰袍踢击或盾击的附近补偿效果隔空击倒，只有真正命中才会触发倒地反应。
- 修复百科按钮、返程纠察队崩溃，以及支援村庄时错误显示劫掠说明的问题。

## 当前可玩内容

- 灰袍声望、犯罪记录、罚金、赎罪、通缉与追捕。
- 村民酬谢、悬赏任务、兵种征调与战场增援。
- AI 领主犯罪执法与百科震慑记录。
- 灰袍专属兵种、六名初始领主及后继者收养系统。
- 灰袍近战踢击、盾击、被动大盾防护及黑金盾外观。
- 与灰袍领主进行城内或野外切磋。
