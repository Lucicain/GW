## 适用与行为

| 身份/兵种 | 窗口 |
|---|---:|
| 灰袍领主/自定义灰袍指挥官 | 5秒 |
| 灰袍新兵gwnewrecruit | 0.5秒 |
| 灰袍轻步兵gwrecruit | 1秒 |
| 灰袍重步兵gwheavyinfantry、弓箭手gwarcher | 2秒 |
| 狂信者、骑士及其他兵种 | 无 |

窗口按用户裁定2026-10-28全部减半，含领主10秒减为5秒；回血、技能倍率及触发条件保持。

按精确兵种ID授予，骑士下马或捡取步兵装备也不获得，外族高阶兵和非灰袍英雄不借兵种ID获得。身份共用[lord-combat](lord-combat.md)判定。（依据：用户最终裁定2026-10-21）

遭受致命身体伤害时留至少1血，窗口内血量不低于1；盾挡/背盾/兵器挡箭产生的盾伤不触发。引擎不死状态不消耗机会。（依据：沿用原领主机制；原版扣血四舍五入及生产实现）

窗口内先累计对敌人的实际扣血；亲手杀死或打晕敌人时按累计伤害回血，最多恢复至血量上限，结束本次锁血，之后致命伤可再触发。命中时不立即回血。友军、非人类目标、溃逃不算成功，领主坐骑冲撞仍记骑手。窗口到期没击杀则释放锁血，本场该Agent不再触发。（依据：用户答复确认2026-10-21；沿用原击杀兑现流程）

## 有效技能而非成长倍率

战狂期间，所有技能的“原版基类技能读取值＋本场该技能累计成长”整体乘1.5并四舍五入，例如200＋100读作450。成长仍按[战斗成长](combat-growth.md)正常增量记录；结束窗口恢复读作300，倍率不会永久写入成长或兵种模板。生命、护甲、装备伤害不额外乘1.5。技能继续通过原版各自效果公式影响速度、精度等表现。（依据：用户答复“所有有效技能×1.5”2026-10-21）

在共享有效技能读取入口ApplyBattleMastery处理倍率；开始、击杀结束、超时释放均UpdateAgentStats刷新原版缓存，不能等下一次击杀/成长才使技能加成生效或恢复。场景成长只记正常增量，结束战狂的击杀也不留下放大成长。（依据：用户更正与原版属性缓存实现2026-10-21）

## 实现、存档与回退

共享GwpLastStandBehavior.DurationFor维护窗口，在伤害模型最后一步限制身体伤害；注册在成长行为之后。每人独立，场景结束消失，无新增战役保存字段或类型。

回退基线d5a8d84中的GwpLordLastStand.cs为最初领主专用机制；本轮前部署ef7e3f7bd264的行为仍在共享工作树。撤本轮分阶DurationFor/Tuning、技能读取倍率及开始/结束刷新，恢复旧成长增量倍率，可恢复前轮顶阶5秒/领主10秒；保留其他共享军械/成长差异，不整文件覆盖。DLL回退需重构建并核对live。（依据：流程2026-10-21）
