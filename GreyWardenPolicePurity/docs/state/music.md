## 何时启用

开战布阵阶段一次性判定，之后不再开关：

- **任意一方开战普通士兵中灰袍占比 >= 50%**。
- 分母是普通士兵：英雄、玩家、马**不计入**；普通灰袍与精锐均按人数。
- 不是战力占比，不是全场双方混算。
- 名单来自原生 `GetAllTroopsForSide`，**含原生预备兵**，在玩家 Agent / PlayerTeam
  与双方出兵名册就绪后读取。
- 之后的伤亡、兵力上限、增援都不重新开关资格。
- 无玩家、多人、友好切磋、无正常战斗 spawn logic 时不启用。
- 仅凭玩家身份或单个灰袍英雄**不再**跳过比例门槛。

资格判定在 `GwpBattleSceneContext`。音乐资格与援军资格是**两套独立判据**，见
[`battle-support.md`](battle-support.md)。

## 强度映射

```
Tension = Exchange * (0.7 + 0.2 * Attrition + 0.1 * Pressure)
```

旧式 `0.7*Exchange + 0.2*Attrition + 0.1*Pressure` 已废除：它让历史伤亡/劣势形成
最高 0.3 的永久底座，高档保留阈值 0.4 之下 Exchange 只需约 0.143 就能一直维持高潮。
现在历史损失只能**放大**真实近期交战，不能单独撑住档位。

档位与防抖：

- 进入高档 0.55，维持高档 0.40
- 升高 3 秒、升中 2 秒、降档 6 秒
- 低档最少持 2 秒，其他档 12 秒
- 12 秒无接触后转低

### 升档额外需要"新鲜交战"

20 秒窗口负责稳定与降档，另有 5 秒窗口 `RecentExchange` 负责升档：

- 按 20 秒阈值等速缩放：`damage/(force*0.025)`、`losses/(force*0.015)`，取 max 限 0–1
- `force` 仍含最近 20 秒阵亡，避免幸存者放大
- **从低/中升高，额外要求最近 2.5 秒有真实命中/伤亡，且 `RecentExchange >= 0.55`**
- 候选不满足新鲜条件就重置为中档候选，不能等 12 秒最短持档结束后把旧爆发补升
- 已在高档的仍由 20 秒窗口平滑维持/回落
- 新战斗清空两个队列；增援不抹除交战历史

这是骑砍适配设计，**不是 GWENT 原版规则**。

## 过渡与播放

- 35 条过渡规则，涵盖原版桥段、低中同时间位置切换、重叠包络样本、开场循环、
  增援打断/恢复最新档位、结尾取消待切换且只播一次。
- 增援到场按 Redraw 完整过渡通知一次，**不逐兵切歌**。双方援军各通知一次。
- 音乐收尾按双方分别查询待生援军（早期版本只防玩家侧，已修）。
- 播放器走原版留给模组的 PSAI 音轨接口；策略请求的档位**不等于**听到换段的时刻，
  还受原版节拍、乐句、过渡段和 Redraw 优先规则约束。

## 渲染

- `GwpMusicScore` 每 20 毫秒的 Render/Current 已去掉 LINQ 排序、闭包与 ToArray
  临时集合，改为直接扫描/倒序清理；同时间控制点保留原稳定优先顺序。
- 淡入淡出仍用原实验室 128 点 Log1 插值；每采样的 Log10 改为类初始化时预计算。
- **无音色变化**：优化前后完整 PCM SHA256 均为
  `B13DB9B252BA9BC848EE67C5AE9A9D90EE566DEBA12D362BBCB3E4DADAD71D80`
  （`MusicTests --fingerprint`，固定 seed 43，320 秒，覆盖 intro/low/medium/high、
  低中互切、分批增援、回落、outro）。
- 未测得具体 CPU/FPS 提升比例，不要声称。
