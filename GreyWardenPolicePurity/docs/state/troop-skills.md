## 基准与范围

灰袍兵技能与实际阶数匹配，六类兵器与跑动按本机六主文化普通/贵族完整升级树119名原版兵种逐项取同阶高值；技能模板继承纳入读取，高阶不会低于低阶已达高点。少数职业在本阶无成熟兵种（如6阶弩）时保留低阶同类高点，骑术原值保持。（依据：用户裁定2026-10-20）
