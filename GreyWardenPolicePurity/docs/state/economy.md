## 公库

- 司法公库就是灰袍族长的钱包（`GetJudicialTreasuryBalance`）。收钱是给族长加金币，付钱是从族长身上扣。
  族长死了或不在时，一律不收不付。
- 灰袍各队的工资照原版家族财务从家族金币里出，和公库是同一笔钱。
- 族长是玩家时，不经公库付钱。

### 收入

| 来源 | 数额 |
|---|---|
| 保护费：全大陆每个村子按当前户数，每户每天 0.05 | NavalDLC 地图开局约 4,900/天，随户数增长 |
| 一件差事成功（`CreditSuccessfulCaseCompletion`）：结案、协力结案、追截收尾、善后完成、重建完成、请愿办完 | 每件 3,000 |
| 玩家缴罚金（不够时没收物品，物品按估值入库） | 实缴 |
| 玩家交差上缴的代收罚金、派使者带回的钱、练兵订单订金 | 实缴 |
| 封地申诉费 | 50,000 |

### 支出

| 用途 | 数额 |
|---|---|
| 重建 | 余额的 3%，取整到百，夹在 15,000–30,000 之间；扣完必须还剩 max(50,000, 7 天工资) |
| 付给玩家的办案报酬、押人收购、撤案辛苦费 | 见 `player-commission.md`、`player-justice.md`；公库不够时付得出多少付多少 |
| 封地申诉失效退款 | 50,000 |
| 重建失败退款 | 当次经费 |

- 每天检查一次：引擎把灰袍家族标记为已消灭时，把这个标记改回去。

## 船只买卖（`GwpLandlessShipTradePatch`，需要 NavalDLC）

- 原版 War Sails 的买船、卖船都按「家族有封地」写，灰袍没有封地，两头都空转：
  - 买：只能走「任意非敌对城镇」的兜底，再叠上外层的概率，全家族每天只有 10% 的机会去看一眼，一天只买一条。
  - 卖：没有兜底，直接返回 null。（依据：C#反编译 v1.4.8 + NavalDLC，2026-09-25）
- 补丁只补「去哪座城」这一步：无封地时，随机挑一座非敌对、能买船的城；卖船挑一座船坞已建成的城（按建筑 id `building_shipyard` 判断）。
  买哪条船、出多少钱、划不划算、卖不卖，仍全部由原版决定：预算闸门、船队组合评分、家族理想船数都没动。
- 灰袍有了封地，补丁就让开，走原版。
- 不引用 NavalDLC 程序集，目标方法在运行时按名字解析；没装 NavalDLC 时 `Prepare()` 返回 false，整个补丁类跳过。
