# 灰袍测试模块与正式玩家包全量对照

本机测试模块为 Bannerlord 1.5.7，灰袍代码截至 `84052d0`。正式玩家包以 GitHub 当前附件为准，1.4.8 和 1.5.7 的附件均逐文件读回并核对整包 SHA-256。两份附件的源码基线分别为 `v1.4-r16.2-sync` 和 `v1.5-r16.2`，均指向 `485bcc4`。1.4 的旧发布页名称沿用，实际附件取同号换包后的版本。 [1.4.8 玩家包](https://github.com/Lucicain/GW/releases/tag/v1.4-r16.2) · [1.5.7 玩家包](https://github.com/Lucicain/GW/releases/tag/v1.5-r16.2)

## 游戏里的变化

| 范围 | 已发布玩家包 → 本机测试版 |
| --- | --- |
| 村庄入口 | 玩家包保留灰袍教众信息及村民打赏。测试版在普通信众村只放一个灰袍入口，有祭司在村时按名字显示「拜访某某」，缺席显示「灰袍教众」。子菜单显示教众和库房概况，设交付、整理军械与卖货。背包卖货按原版村庄市场收第纳尔，村庄招募及要人对话沿原版入口。 |
| 交给祭司 | 测试版可从子菜单或祭司对话交普通俘虏。声望超过 20 后还能交普通非灰袍兵给村民兵，或在储藏双栏里交付主队军械。普通人按一至六阶记 1 到 6 权重点，每 20 点换 1 灰袍声望。军械按当地原版出售估价每 600 第纳尔换 1 点，各自保留尾数。交付界面底部预览实际声望。 |
| 战斗与声望 | 玩家包的行善按玩家个人击倒人数记分。测试版按敌人阶级累计，胜方玩家亲自击倒或击杀计全权重，主队士兵计四分之一，含原版派兵，跨战与读档保留尾数。战报预览的是本场灰袍声望。护村转野战保留原村及选边，修复了护村结算和后续调停。 |
| 切磋与主队兵 | 测试版赢灰袍领主的友谊赛加 1 点声望，城内外共用一天冷却。新接收的灰袍兵按当前声望两倍取整核对名额，超编现有兵保留。灰袍兵升阶五次累计扣 1 点声望，仍消耗原版经验和必需物品，完成前预览扣点。 |
| 练兵下单 | 玩家包按声望档解锁和用金币订兵。测试版当面或派使者都能用原版部队页混订，按阶逐项精算声望，原料在练兵官手上练，随队只装已练成的成品，取消不下单。备齐的订单照常交付，超出名额的兵可保留。 |
| 军械库 | 测试版主队按可带兵上限分别保留每个防具部位及各类武器，单手、双手、长杆分开。普通兵可按原配选择同类同等或更强的装具，肩甲纳入，军械确认与取消沿原版界面。 |
| 家族本职与震慑 | 玩家包分别有护村与商队护卫，震慑分两本账。测试版合并成「灰袍乡路巡法者」，约珥和弥瑟同任，本职剩五类。袭击村民、商队和烧村共用各领主的震慑和被捕下限，派案、百科和事务一并对齐。 |
| 罚款 | 正式灰袍领主当面缴罚从 100 提到每点负声望 200 第纳尔，同纠察队的费率。查账仍按每 100 第纳尔折一点，正式灰袍战败押送仍走 300 的流程。 |
| 招募与使者 | 测试版招募使者主动上前进入会面，保存出发和返程阶段，祭司的原版招募首格对玩家也锁住。玩家派出的使者在 1.5.7 用新的地图标记入口登记和清除，用户已确认标记修复。 |
| 复命交易 | 已发布的 1.5.7 DLL 在当前预检能绑定 116 个补丁类，但查到 `GwpAssetAutoOfferPatch.Label` 为空。原版删掉了它要调用的按钮刷新，城内搜捕复命点「配平」会触发这条故障。测试版按两代接口走，反射空句柄为 0。 |
| 村民打赏与成就 | 玩家包有村民打赏、领取滑条和两条成就兼容补丁。测试版删去打赏及累计，旧余额随原行为退休。成就资格交回原版或玩家启用的成就模组。 |
| 旗帜 | 正式玩家包仍用首版打包纹理。本机测试模块换单层旗帜图集及缓存，低画质模糊已经由用户确认解决。 |

存档差异集中在订单组合和价款、升阶与声望尾数、切磋冷却、地图战果与护村状态、三类个人交付累计。旧的村民打赏和分类商队震慑记录及练兵队调货状态从现行保存退出。村庄子菜单复用原有村庄、祭司、交付和市场数据。现行读取按各属主的接续规则处理，现场验收范围见[声望](../state/player-justice.md#加分)、[订单](../state/troop-orders.md#订单阶段)和[村庄](../state/firesworn-villages.md#待实测)。

## 同源码的测试版和无诊断构建

测试模块含 AI、案件、运行故障和交付诊断，库房明细和领主军械库问询只在诊断构建中注册。隔离的 1.5.7 无诊断构建保留本次拜访与交易入口。实测预检分别绑定 133 和 128 个补丁类，两者均通过。5 个开发版补丁是 `GwpArmyInfluenceFailureTracePatch`、`GwpDispatchBarterFaultDiagnostics`、`GwpEngineAssertDiagnostics`、`GwpFireswornUpgradePaymentTracePatch`、`GwpInitiativeDiagnosticsPatch`。旧版对照使用实际公开 DLL，现行无诊断 DLL 仅供本轮隔离核对。

本机镜像的 74 个运行时文件、Client/Editor 的 DLL/PDB、新语言 XML 经比对。1.4.8 以对应引用程序集编译和核对，1.5.7 另做实际加载与 Harmony 预检。107 项规则测试、27 项工具自检、文本键和独立复审通过。村庄子菜单实际显示、几种交易的确认与取消、返回和特殊村庄仍按正常游玩验收。
