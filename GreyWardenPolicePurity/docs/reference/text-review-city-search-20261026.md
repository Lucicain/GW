# 进城搜捕：按游玩顺序审阅台词

2026-10-26 修订稿，待用户审核。尚未写入 `PlayerText/strings.json` 或语言文件。

以下是拟写的游戏台词。场景说明供审阅，不会让角色念出来；每组玩家回应是可选分支，不是连续说四遍。方括号只标注现场情况。

## 一、带着部下进城，卫兵迎上来

卫兵：站住！带着这么多兵进城，你们想做什么？

玩家：灰袍托我来找{TARGET}。人在领主大厅，我们过去找人。

玩家也可以结束交谈：我们这就出城。

卫兵：带着兵找人？城里出了乱子，谁来收拾？

玩家可以回答：

1. 我的人听我的。谁敢在城里惹事，我亲自收拾。
2. 我们只找那个人，不为难旁人。找到就走。
3. 人就在城里，你却拦着不让找。我要是空手回去，该怎么跟灰袍说？
4. 我的人不会白拿城里一件东西。该付的钱，一文不少。

[卫兵有所松动，仍不肯轻易让开。]

卫兵：就凭你几句话，我怎么知道你说的是真是假？

玩家可以回答：

1. 你看着，我的人都在这里。进城以后也跟着我，一个都不会散开。
2. 我来找谁、替谁办事，都已经说了。真想闹事，何必站在这里跟你解释？
3. 要是有一句假话，我亲自到你家大人面前领罪。
4. 你拦住了我们，可那个人要是趁这会儿走了，到时候谁来解释？

卫兵被说动：……好，你接着说。

卫兵不信：少来这套。

卫兵失去耐心：够了！别再跟我耍嘴皮子。

[最终放行。]

卫兵：去吧。别在城里惹事。

[最终拒绝。]

卫兵：不行。带着你的人出城去。

玩家：好，我们撤。

或者：那就从你们身上踏过去。

## 二、进了大厅，目标转过身来

[你和部下已经走进大厅。目标可能是这里的主人，也可能只是暂住的客人。]

领主：带着这些人来找我，有什么事？

玩家：灰袍让我把你带回去。跟我们走。

玩家也可以离开：我先告辞。

领主：灰袍让你来的？我可没答应跟你走。

玩家可以回答：

1. 你做过的事，不能就这么算了。自己跟我走，还能留些体面。
2. 被你害的人还等着一个交代。别再为这件事添人命了。
3. 你要我在这里，当着所有人的面，把事情再说一遍？
4. 你也不想这事闹得满城皆知。跟我走，咱们安静地出去。

[目标开始考虑同行，但担心接下来的处境。]

领主：你把我带走以后，打算怎么处置我？

玩家可以回答：

1. 我会把你交给灰袍。路上有我看着，没人能私下动你。
2. 真动起手来，刀剑可不长眼。趁现在还没见血，跟我走。
3. 敢做就敢认。别到这时候，还要身边的人替你出头。
4. 我接的是带你回去的差事。活着把你交到灰袍手里，我也好交差。

领主愿意继续听：……接着说。

领主拒绝这个说法：这话留着去骗别人吧。

领主失去耐心：够了！我不想再听你说了。

[最终答应同行。]

领主：好，我跟你走。让你的人把兵器收好。

## 三、谈不拢，对方提出单挑

领主：你要抓的是我。你我单打，赢了我就跟你走。

玩家接受：好，就你我两个。我赢了，你跟我走。

领主：好，就这么定了。

[若玩家坚持一起动手。]

玩家：都动手，把人拿下！

领主：那就试试！

## 四、谈不拢，对方要与守卫一起迎战

领主：少废话。你们敢上前，就别想站着出去。

玩家选择动手：都动手，把人拿下！

领主：上！

[若玩家仍想单挑。]

玩家：你我单打。我赢了，你跟我走。

领主：我凭什么答应你？

玩家可以回答：

1. 就你我两个，输赢都认。我输了，带人走；你输了，跟我走。
2. 我就在这里。你连亲自拔剑的胆量都没有？
3. 你真想让这大厅里躺满人？我们两个就能了结的事，何必把他们拖进来。
4. 当着这些人的面，你倒是站出来啊。

[对方答应。]

领主：好。让你的人退开。

[对方不答应。]

领主：少费口舌。想抓我，就上来。

## 五、离开大厅、赴约与出城

[已经约好在竞技场单挑。]

提示：去竞技场赴约。

[大厅里的事处理完，带队离开。]

提示：带上部下，出城。

[守卫倒下，可以继续往大厅去。]

提示：带上还能行动的部下，去领主大厅。

[正在杀出城。]

提示：带着部下撤到城门外。

[无武器的目标逃跑。]

提示：目标逃走了，追上去！

操作说明仍放在需要操作的地方：城门外可按住 Tab 离场；交战时尚未到城外，提示“还没出城，无法离开。”。这些是界面反馈，不塞进人物台词。

## 这次分开写的上下句

对方先提出单挑，玩家说“好，就你我两个”；对方威胁群殴，玩家说“你我单打”。同意单挑之后用“好，就这么定了”，混战开始时用“上！”。这四处按各自上下句写，批准后再拆现有共用条目。

## 作者核对记录

- 主角是受托来抓人的玩家，开场用“灰袍托我”，不冒称灰袍成员；目标不一定拥有这座大厅，去掉“我的大厅”。
- 去掉令状、印信、当面对质和审判程序；不编造守卫收走私钱的既往事实。
- 不保证家属必来赎人，不把被俘说成可以自在答辩；人物只承诺自己押送时能做到的事。
- 不让领主念出“我的人挡不住你们”“你是仗着人多”等判定解释。选择单挑也可能出于性格和个人本领，台词不替他断言怯战或必败。
- 现有第二组卫兵回应中的“派人跟随”未写入新稿，因为没有随行监督的实际动作；新稿只让玩家表明自己如何约束部下。
- 失败反应要能接住当前组的每种说法；普通劝说失败也可能令对方失去耐心，不一律指责玩家“威胁”。
- 对话的顺序、结果出口及实际去向按现有代码核对；这是新拟稿，不是用户已经批准的原文。
