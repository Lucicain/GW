> 灰袍起初是帝国教会中承担巡察与惩戒的一支修会。帝国分裂后，她们脱离了诸侯的统辖，仍奉上天的诫命约束自身，也要求旁人守戒。修会由女性统领，教士在各地传教，村中的教众为她们提供兵员与供给。她们缉捕劫掠者，保护村庄与商路，并把惩戒罪行视为信仰的一部分。平民依靠她们的庇护，也畏惧她们严苛的审判。

## 稿件中的处理

- 旁白写眼前发生的事。火刑仍是火刑，实际会涉及俘虏、民兵和不信教户，不把所有受刑者改写成已查明罪行的犯人。
- 普通对话交代来处、去向和目的。有关宗教的说明集中在介绍、教士生平和仪式，不给每个按钮加一层祝福。
- 建议称呼为“灰袍教士、灰袍教众、灰袍传教队、灰袍狂信者”；“信众村”留作开发用语。现有类名、文件名、文本键与存档字段均保持原名。
- 仪式HOST在没有教士时会显示村名，拟稿用中性的“主持：”承接，避免把村名写成一个正在讲道的人。
- 开发版库房入口不出现在玩家发行版，仍列入清单并明确标注；不据此增加玩家功能。
- 问候后的衔接句可能重复询问来意，现有对话流未动；实施时若要合并句子，应另核对对话分支，不能靠改一条文本假装已经改了流程。
